# YU STUDIO｜小宇工作室

工作室網站：服務介紹、作品、合作流程與專案洽詢。支援繁體中文、英文及日文。

本專案後續更新的唯一遠端儲存庫為 https://github.com/yustudio0801/yustudio0801 。

## 本機預覽

使用 Python 啟動靜態伺服器：

```sh
python -m http.server 18473 --bind 127.0.0.1
```

開啟 http://127.0.0.1:18473/ 。網站不需要建置步驟或套件安裝。

## 網站檔案

- `index.html`：頁面與繁體中文內容。
- `style.css`：響應式版面與視覺樣式。
- `script.js`：語言切換、導覽與需求清單複製。
- `favicon.svg`：工作室識別。

公開聯絡信箱：yuuuchen1@gmail.com。企業作品英文名稱：Besta SV。

## 發布

可將網站檔案交由靜態網站主機發布；若使用 GitHub Pages，於儲存庫 Pages 設定選擇 `main` 分支與根目錄。
Git 推送與網站啟用是兩個獨立步驟。
